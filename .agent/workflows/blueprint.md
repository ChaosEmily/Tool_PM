# 核心藍圖生成器 (Blueprint Generator)

為了確保 Vibe Coding 一次到位，我們需要定義以下「第一性原子」：

1. **數據原子 (Atoms)**：這個 App 處理的最基礎對象有哪些欄位？(名詞 - Nouns)
2. **物理定律 (Laws)**：有哪些禁止行為或連鎖反應？(動詞 - Verbs / JavaScript 引擎邏輯)
3. **生存環境 (Envir)**：誰可以看、誰可以改？(權限與環境)
4. **記憶深度 (Memory)**：資料需要存多久？存在哪？
5. **核心入口 (Focus)**：使用者打開的前 5 秒最想做什麼？

---
### 💡 關鍵觀念：JS 動詞思考法
雖然你不需要寫代碼，但你必須明確告訴 AI：**「當 A 發生時 (觸發)，B 應該要怎麼變 (JavaScript 邏輯)？」** 這是賦予 App 生命的核心引擎。
