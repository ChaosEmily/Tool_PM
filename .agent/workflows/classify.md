# 專案定位器 (Project Classifier)

請向我描述你的專案想法，我將會執行以下五項測試：

1. **數據生存週期 (Persistence)**：重新整理後，資料需要留著嗎？
2. **交互密度 (Interaction)**：是以「看」為主，還是以「操作」為主？
3. **組件連動 (State)**：畫面不同處是否需要即時同步？
4. **協作性 (Social)**：是否需要多人實時同步？
5. **導覽模型 (Navigation)**：追求網頁跳轉，還是 App 的無縫體驗？

---
### 執行指令
請輸入專案簡單描述後，我會給出 **「選型結論」** 與 **「推薦技術棧 (Stack)」**。
