# Vibe Coding 執行流程 (The Vibe Flow)

在正式寫代碼時，請遵循以下 4 階段：

### 階段 1：地基 (Stack Selection)
- 定義好 **React + Vite + Tailwind + Supabase** 的組合。
- 讓 AI 初始化專案文件結構。

### 階段 2：大腦與引擎 (State & JS Logic)
- 先建立 `Data Center (Context)` 與 `Schema` (名詞定義)。
- **重點**：理清 JavaScript 邏輯（動詞定義）。在畫面出來前，先把「當 A 觸發時，B 資料該如何運算」寫成明確指令。

### 階段 3：零件 (Componentization)
- 一次只做一個小組件（看板、按鈕、列表）。
- 採用 **「做完一個就驗證一個」** 的策略。

### 階段 4：調優 (Polishing)
- 加入 Tooltips, Animations, 響應式佈局。
- 處理邊緣案列 (Edge cases)。
