# Vibe Coding OS 

歡迎使用 Vibe Coding 開發作業系統。在開始前，建議建立 **「名詞 (Data) - 形容詞 (CSS) - 動詞 (JS)」** 的核心思維。請根據目前的進度選擇指令：

### 1. 專案定位 (/classify)
當你有一個點子，但不確定該用什麼技術架構開始時。
- 使用 **`/classify`** 啟動 5 大通用標準測試。

### 2. 核心規格書 (/blueprint)
如果你確定要做 App，需要一份精準的發展藍圖。
- 使用 **`/blueprint`** 協助你定義數據原子、物理定律與核心路徑。

### 3. 開發流程導引 (/vibe-flow)
當你準備好開始寫代碼，需要一套防呆的 Vibe Coding 執行步驟。
- 使用 **`/vibe-flow`** 獲取 4 階段執行指南。
